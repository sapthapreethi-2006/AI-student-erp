# 🎓 AI-Powered Student ERP Management System
## 📖 About

AI-Powered Student ERP Management System is a full-stack web application developed to simplify educational institution management. The system enables administrators, faculty members, and students to manage academic activities efficiently. It also integrates Google Gemini AI to provide intelligent assistance for academic queries.
## 🎯 Objectives

- Simplify student management
- Digitalize academic records
- Reduce manual work
- Improve communication
- Integrate AI assistance
## ✨ Features

- Student Management
- Faculty Management
- Department Management
- Course Management
- Attendance Tracking
- User Authentication
- Role Based Access
- Dashboard
- AI Assistant
## 🤖 AI Assistant

The application integrates Google Gemini AI to answer academic queries, provide learning assistance, and help users quickly access information through an intelligent chatbot.
